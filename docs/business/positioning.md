# Aeria — Positioning

## Positioning statement

For Apple users who want privacy without complexity, Aeria is the VPN that feels like it was built by Apple itself — private, fast, and radically simple — unlike mainstream VPNs that bury protection under server lists, upsells, and jargon, or privacy-purist VPNs that neglect craft and platform polish.

## Elevator pitch

Aeria is a premium VPN built exclusively for the Apple ecosystem. Open the app, tap Connect, you're protected — no server lists to study, no upsells, no technical overload. Privacy, beautifully simple.

## One-sentence pitch

Privacy, beautifully simple.

## Brand principles

1. **Quiet** — no urgency marketing, no countdown timers, no fear-based copy.
2. **Expensive-feeling** — restrained visual language, generous whitespace, no gradients-for-the-sake-of-gradients.
3. **Trustworthy** — every claim is technically defensible (see `/docs/business/positioning.md#security-claims-policy` below); never "100% anonymous," never "unhackable."
4. **Modern** — contemporary Apple-adjacent design language, not cloned Apple assets (brief explicitly prohibits copying Apple's proprietary visual identity).
5. **Intelligent** — copy respects the reader; no dumbing down, no jargon overload either.

## Security claims policy

Aeria will never market itself as "100% anonymous," "impossible to track," or "completely unhackable." All security claims must be technically defensible and specific (e.g., "we do not log browsing history" rather than "totally private"). Independent-audit claims ("Independently audited") are used only after an actual completed audit — not aspirationally. See `/docs/security/THREAT_MODEL.md` and `/docs/security/data-collection.md` for the underlying claims these are grounded in.

## What Aeria explicitly does not lead with

- Server count / country count.
- Feature count / bundled tools.
- Discount-driven pricing hooks ("70% off!").

These are the exact commodity dimensions competitors compete on (`/docs/business/competitive-analysis.md`) — leading with them would put Aeria in a race it doesn't need to run.
